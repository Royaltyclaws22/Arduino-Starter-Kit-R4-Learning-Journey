# ⚙️ Motorized Pinwheel

In this project, I built an Arduino-controlled motorized pinwheel that demonstrates how a *pushbutton* can be used to control a *DC motor* through a simple digital circuit.

This project is based on Project 09 from the Arduino Starter Kit R4.

## 🎯 Objective

The purpose of this project is to learn how to use a *transistor*, a *diode*, and a *DC motor*, as well as how to control higher-current loads safely.

---

## 🔋 Components

List of hardware components used:
- Arduino UNO R4 WiFi Board
- USB-C Cable
- Breadboard
- 1 x 10 kΩ Resistor
- 1 x Diode
- 1 x Pushbutton (Switch)
- 1 x MOSFET Transistor
- 1 x Small DC Motor (6/9 V)
- 1 x 9V Battery Snap Connector
- 1 x 9V Battery
- Solid Core Jumber Wires
- Stranded Jumper Wires
