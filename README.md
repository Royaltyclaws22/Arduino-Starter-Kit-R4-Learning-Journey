# 🤖 Arduino Starter Kit R4 Learning Journey

This repository documents my journey learning electronics and programming with the Arduino Starter Kit R4.

Arduino Starter Kit R4:
[https://store.arduino.cc/products/arduino-starter-kit-multi-language](https://store.arduino.cc/products/starter-kit-r4?queryID=undefined)

---

## 🗃️ Repository Structure

| Folder | Description |
|--------|-------------|
| 01_Get_to_Know_Your_Tools | Simple circuits with LEDs, switches and resistors |
| 02_Spaceship_Interface | Control panel simulation for a spaceship |
| 03_Chill-o-Meter | Temperature monitoring system |
| 04_Color_Mixing_Lamp | Color-mixing RGB LED system |
| 05_Mood_Cue | Servo motor control system |
| 06_Light_Theremin | Light to audio tones translation system |
| 07_Keyboard_Instrument | Musical keyboard instrument |
| 08_Digital_Hourglass | Interactive digital hourglass system |
| 09_Motorized_Pinwheel | Interactive motorized pinwheel system |
| 10_Crystal_Ball | Interactive digital fortune-teller |
| 11_Knock_Lock | Knock-detecting lock mechanism |
| 12_Touchy-Feely_Lamp | Interactive capacitive touch lamp |
| 13_Hacking_Buttons | Automated button-pressing interface |

Each project contains its own README with the following sections:
- Project Description
- Circuit Demo
- Objective
- Components
- Circuit Implementation
- Setup & Upload
- How it Works
- Code
- What I Learned
- Future Improvements

The projects in this repository are based on the official Arduino Starter Kit R4 projects and documentation. 
I have built the circuits myself, captured my own photos, written my own explanations, and adapted or rewritten the code while experimenting with different implementations.
